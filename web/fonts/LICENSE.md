# Písma pro mapu

Předpřipravené glyfy (`.pbf`) pro popisky na mapě. Leží tady schválně:
appka je servíruje z vlastní domény, takže při vykreslování mapy nesahá
nikam ven (`R2`, `R12`).

| | |
|---|---|
| **Písmo** | Noto Sans (Regular, Medium) |
| **Licence** | SIL Open Font License 1.1 — použití i šíření povolené, včetně komerčního |
| **Odkud** | `github.com/protomaps/basemaps-assets`, adresář `fonts/` |
| **Rozsahy** | `0-255` (základní latinka) a `256-511` (rozšířená latinka — česká diakritika) |

⚠️ **Další rozsahy budou potřeba, až se produkt rozšíří mimo latinku.**
Řecká, cyrilská nebo arabská jména se bez nich na mapě nevykreslí — a nespadne
to, jen tam nic nebude. Doplňují se stažením dalších `.pbf` ze stejného zdroje.
